How the course works

One small idea per lesson

Start with Foundations

Module 00 explains the basics: files, tables, Spark, cloud storage. Skip it only if you already know them.

Go in order

Each lesson lists what to read first. Later lessons use words that earlier ones explain.

Click things

Change an option in a demo and watch what breaks. That is how the "what if" questions in the exam become easy.

Use the glossary

Every new word links to the glossary. Nothing is left unexplained.

Check the official docs

Each lesson ends with links to the official pages and the date it was last checked.

About the exam
