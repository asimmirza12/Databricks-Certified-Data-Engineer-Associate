# Data engineering on Databricks, from zero

A free, interactive course for complete beginners, following the Databricks Certified Data Engineer Associate exam guide.

**Live course: https://asimmirza12.github.io/Databricks-Certified-Data-Engineer-Associate/**

> **Learning resource only.** This is an independent, unofficial study guide made for learning purposes. It is not affiliated with, endorsed by or sponsored by Databricks. Databricks features change often, so always check the details in the official Databricks documentation (https://docs.databricks.com) and the official exam guide on databricks.com before relying on anything here. ## What it is

- Written for people who are new to data engineering and new to Databricks.
- One small concept per lesson: plain-English explanation, animated diagram, clickable demo, code, "what if I change this?" table, exam traps and a quiz.
- Starts with a Foundations module, then one module per exam guide section, in the guide's order.
- Progress is saved in your own browser. No account, no tracking.

The full plan and what is published so far: [OUTLINE.md](OUTLINE.md).

## Run it locally

No build step. From the repo folder:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.
